# 将来の積み上げ予測

入口: 未来決算 > 予測 > 利益剰余金・返済後の将来予測。
ルート `/mirai-kessan/forecast/wealth`。ダッシュボード権限が必要。

「何年後？」は1〜100の整数。選択年は現在の暦年＋入力年数の9月末。
今期末・来期末も比較表示。今月1日から予測を累積する（今期の過去月全体の予測ではない）。
初期残高がなければ増加分のみ。入力残高の基準月を保存し、月が変わればそのまま流用しない。

## 計算

既存の税込収支と整合させ、消費税納税見込を1度だけ差し引く。
期の税引前利益 = 各月の税込営業収支 - 消費税見込 - 追加利息 - 追加減価償却。
法人税等 = max(0, 期の税引前利益) × 設定した概算税率。
利益剰余金増加 = 税引後利益 - 配当。
返済後残額 = 利益剰余金増加 + 減価償却 - 元金返済 - 設備投資。
開始残高は2系列で独立。

税引後利益に減価償却を加え、元金返済を差し引く考え方の参考:
https://www.jfc.go.jp/n/finance/sougyou/sougyou02.html

## 前提と限界（画面でも表示）

- 今月は既存の月次予測を使用。将来月は最新の同月実績が14日以上あれば、その日平均を使用。
  なければ今月日平均で仮置きし、季節差未反映の月を表示。5年限定ではない。
- 人件費・固定費は今月見込を継続。売上の年変化率と人件費・固定費の年変化率は独立。
- 元金・追加利息は返済終了月の翌月から0。空欄なら継続。元金は空欄だと既存の返済月額。
  既存額が利息込みの場合は元金を明示修正する。
- 消費税は売上10/110から控除見込を引く。原価に対する入力税額比率は直近3か月＋今月。
  登録広告費の控除と追加控除設定も反映。その他固定費の未登録控除や還付は自動推定しない。
- 法人税率は勝手に設定しない。期内損失を相殺するが繰越欠損金・均等割・期の過去月損益は未対応。
- 追加利息・償却は既存経費と重複させない。償却/設備投資は税率を扱わない個別設定額。
- 売掛買掛・在庫増減・新規借入・個別将来月の給与/費用は未反映。銀行残高や確定決算ではない。
