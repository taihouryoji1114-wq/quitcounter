# 月次印刷のジャンル別ページ

未公開。対象：pages/financial_reports.py、core/financial_report_pdf.py、test_financial_report_layout.py。

ブラウザ印刷・ダウンロードPDFを5ジャンルに分割。
1. 売上・利益、重要な経営比率、利益ブロック、税金・返済の調整
2. 営業経費の内訳
3. 決済方法別集計
4. 仕入れ先別集計
5. 日別売上明細

各ジャンルは新しいページから開始。多い明細は同ジャンルとして継続し表見出しを反復。比率・利益ブロックを先頭1枚にまとめる。各ジャンルに集計期間、PDFにはページ番号。
月選択と「この月を表示」で1日〜末日に切替。既存期間指定も維持。金額計算は変更なし。PDF利益ブロックの段落文字色も白に明示して読みやすくした。

検証：テスト1件で改ページの順序とまとめページの内容を確認。UI構築確認。31日・仕入れ先16件のサンプルPDFが5ページ、80件では仕入れ先が続きページとなり日別は独立。PDFテキスト検証・PNG描画でまとめ、明細、継続ページの収まり確認。ブラウザの実印刷プレビューは未実施。
