# ゲーム開発ロードマップ

## 現在の開発：神獣札

目的は、Godotでどこまで高品質な演出・戦闘・育成ゲームを作れるかを実物で確認すること。

- Godot版を本制作の基準とする
- iPhoneでの試遊は、停止しにくい軽量ブラウザ版にも同じ内容を反映する
- 探索、遭遇、カード召喚、戦闘、契約、育成までを一つの短い完成体験にする
- 手応えが十分得られた時点で、次の最優先企画へ移る

## 最優先企画：CODE BEASTS（オリジナル・デジタルモンスターRPG）

「デジタルモンスターを、自分で探索して出会い、仲間にし、育て、冒険とバトルを楽しむ」ゲーム。
既存作品のキャラクター・名称・世界観は使わず、完全オリジナル作品にする。

想定する核：

- フィールド探索
- モンスターとの出会い
- バトルを通じた仲間化
- 育成と進化
- パーティ編成
- 町、道、ダンジョンを巡る冒険
- モンスターがデータとして生まれた理由を物語の中心にする

位置情報は初版に入れない。位置情報がなくても面白い探索・育成・戦闘を先に完成させる。
完成後、現実の移動がゲーム体験を本当に良くする場合のみ追加を検討する。

初版は横画面専用。iPadを基準に、研究所で相棒を選ぶ、町と草原を歩く、野生データと遭遇する、戦闘して仲間にする一連の体験から完成させる。
